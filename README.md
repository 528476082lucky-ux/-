# Photo Gallery Creative Website
> Turn shared memories into a revisit-able webpage
> 把共同经历，整理成可回看的网页

## 📌 项目简介
这是一个照片创意交互网站设计项目，聚焦共同回忆的收集、整理与浏览，包含照片上传、选择、反馈查看、撕拉片创意展示等交互界面。
本仓库存放项目说明文档与UI界面设计稿。
